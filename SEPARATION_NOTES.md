# Previous Backend - Separated API/Data Layer

This package is based on the supplied previous backend and keeps the full Next.js API/data layer, Prisma schema and seeds, scripts, uploads, documents, downloads, and original assets.

Additional read-only API routes were added for data that the previous combined UI used to read directly through Prisma: certificates, partners, testimonials, countries, public settings, industry detail, and sitemap data. Existing API routes and data files were retained.
